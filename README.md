# Scratchy Nets

Building simple neural networks from scratch, inspired by Andrej Karpathy's [Neural Networks: Zero to Hero](https://www.youtube.com/playlist?list=PLAqhIrjkxbuWI23v9cThsA9GvCAUhRvKZ) YouTube series.

## Contents

- `01 Bigram.ipynb` - Bigram character-level language model
- `02 Simple MLP.ipynb` - Multi-layer perceptron implementation
- `03 Backprop verifier.ipynb` - Verifying backpropagation calculations

## Data

- `names.txt` - Dataset of names for training character-level models
